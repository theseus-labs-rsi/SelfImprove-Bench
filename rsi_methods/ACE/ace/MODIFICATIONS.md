# Modifications

This directory contains a modified copy of ACE (Agentic Context Engineering),
originally from <https://github.com/ace-agent/ace>, licensed under the Apache
License 2.0 (see `LICENSE.txt`).

The SelfImprove-Bench authors modified this copy to adapt ACE to the
SelfImprove-Bench benchmark harness (task execution, refinement and selection
interfaces, logging, and game integrations). The adapter that connects ACE to the
benchmark is `../ACEAdaptor.py`.

These modifications are provided under the same Apache License 2.0.
